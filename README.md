# Backend Architecture Lab implementations

Implementation code and implementation-specific documentation belong in separate directories: `nestjs/`, `golang/`, `rust/`, and later `springboot/` or others. Lessons and the cross-language roadmap live in the parent directory. Start by following [Lesson 01](../lessons/01-nestjs-product-api.md); its NestJS CLI command creates `nestjs/`.

Each implementation should document its own setup, decisions, tests, benchmark conditions and operational trade-offs as it evolves. Equivalent API behavior and workloads enable meaningful comparisons; internal designs may differ where the language or framework warrants it.
